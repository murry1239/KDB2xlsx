## 2. 확정된 작업 흐름 (alpha_0.3.1)

1. **A 탭** — txt 폴더 → `_01`, `_02`, `_03`
2. **사용자** — `_03` 파일 EVENT 시트에 **PT_한국어, SOC_한국어** 입력 후 저장
3. **B 탭** — `_03` 파일 → `_10`, `_20`, `_30`
4. **사용자** — `_30` 파일을 확인하며 **LLT_한국어, 반영여부** 직접 입력 (DRUG_EVENT 1행 제목만 만들어 둠)

입력값 예시

| 항목 | 글리팜정4mg | 그리타존정 (claude.ai 채팅) |
|---|---|---|
| 제품명 (파일 이름) | 글리팜정4mg | 그리타존정15mg |
| 의약품명 (DRUG 시트) | 글리팜정4밀리그램 | 그리타존정15밀리그램 |
| 시트 이름 앞부분 | 글리팜정 | 그리타존정 |

- DRUG [의약품명]은 README의 `요청 품목코드`와 DRUG_CD가 같은 행에 입력
- 결과 저장 기본 폴더: txt 폴더가 `files`이면 그 상위(접수번호) 폴더

## 3. 실제 자료로 찾아 고친 오류

| 증상 | 원인 | 수정 버전 |
|---|---|---|
| DEMO [연령단위]가 빈칸 | 원본 코드가 `00103`처럼 앞자리 0, 변환표는 `103` | 0.1 |
| exe 출력을 파일로 돌리면 멈춤 | `✔` 문자가 한글 Windows(cp949)에 없음 | 0.1 |
| exe 실행 후 결과 파일 없음, 창이 바로 닫힘 | 제품명의 `/`(예: 글리팜엠정2/500)로 파일 저장 실패 + 예상 못한 오류를 잡지 않음 | 0.2 |

- 0.2부터 파일 이름 금지 문자 `\ / : * ? " < > |`는 `_`로 바꿔 저장
- 0.3부터 모든 오류를 알림 창과 로그(`%LOCALAPPDATA%\원시자료정리봇\logs`)에 기록

## 4. 검증 결과

- **글리팜정4mg (2610B0048):** DRUG_EVENT 190행, `#N/A` 없음. _30 파일: 원본 190행 / 글리팜정_의심 6행 / 글리팜정_병용 15행. 의심·병용 행 수는 txt에서 직접 센 값과 일치
- **글리팜엠정2-500 (2610B0045, 보고 1건):** 6개 파일 생성, 의심 1행 / 병용 0행
- **버전 간 비교:** alpha_0.3·0.3.1 결과가 alpha_0.2와 6개 파일 모두 같음. 다른 것은 사용자 입력 열뿐
- **화면:** A·B 버튼 동작, 오류 알림 창, 로그 파일 생성은 자동으로 눌러 보는 방식으로 확인. exe와 RUN.bat 모두 창이 열리는 것 확인
- **회귀시험:** 가상 자료(실제 이상사례 아님) 5개 통과 (`TEST.bat`)
- **아직 확인 못 한 것:** 수작업 정답지와의 셀 단위 비교는 그리타존정 한 건뿐(claude.ai 채팅). 글리팜정·글리팜엠정은 정답지가 없음

## 6. 개발 기간 비교 (변분기·변대생기 대비)

변분기·변대생기는 버전을 여러 번 거쳐 개발했고, 원시자료 정리봇은 약 2일 만에 원하는 수준이 되었습니다. 주요 원인은 다음과 같습니다.

1. **요구사항:** 정리봇은 명세(열 위치, 변환표, 수식, 필터)가 완성되어 있었음. 변분기는 "무엇이 변경인가"(서식만 다른 블록, 목차·별첨 범위 등)를 실제 문서로 개발하면서 찾아야 했음
2. **입력:** 고정 형식 txt 13개 vs 문서마다 구조가 다른 DOCX
3. **외부 프로그램:** 정리봇은 openpyxl만 사용. 변분기는 Word 자동화(페이지, 이미지 캡처)가 필요했고, 개발 환경에서 Word를 실행할 수 없어 실제 시험을 사용자가 대신 해야 했음
4. **정답지:** 정리봇은 수작업 결과와 기계적으로 비교 가능. 변경대비표는 사람의 판단이 필요해 매칭 수정 화면까지 만들어야 했음
5. **경험 재사용:** 2단계 분리, 화면·로그·BAT 구성, 사람이 판단할 부분 따로 빼기 등 변분기·변대생기에서 정한 구조를 그대로 가져옴

다음 자동화 업무에 적용할 점: ① 수작업 절차를 명세로 적고 정답지 결과물을 함께 준비 ② 사람이 판단할 부분은 처음부터 입력 단계로 분리 ③ 실제 PC와 실제 자료로 바로 실행할 수 있는 환경에서 개발
